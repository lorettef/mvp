Place `hero.mp4` (5-7 seconds, muted, < 5 MB) in this directory to enable the
landing-page background video.

Until this file is added, the landing page (`/`) falls back to a dark gradient
background and renders correctly.

Recommended: a subtle, dark, abstract motion loop (e.g. blurred data/network
particles or a slow city-timelapse) so the headline text stays legible.
