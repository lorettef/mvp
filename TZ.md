1. ЦЕЛЬ ПРОЕКТА
Создать B2B-платформу для акселераторов и венчурных фондов, которая позволяет:
1. Собирать данные о портфельных компаниях (План и Факт по метрикам, когортам, бюджету).
2. Анализировать юнит-экономику и когортное удержание в динамике.
3. Управлять задачами по подготовке к продаже бизнеса или его части (главное УТП).
4. Генерировать AI-рекомендации по улучшению показателей.
5. Анализировать внешнюю среду (рынок, макроэкономика).
6. Прогнозировать найм сотрудников с учётом ФОТ и настраиваемых соц. платежей.
7. Формировать P&L, Cash Flow и оценку бизнеса по модели Гордона.
8. Предоставлять отчёты для инвесторов (PDF, Excel).

4. РАСШИФРОВКА КЛЮЧЕВЫХ МЕТРИК
- MRR (Ежемесячный доход)           -> Сумма регулярных платежей (₽).
- CAC (Стоимость привлечения)       -> Затраты на маркетинг и продажи / Новые клиенты (₽).
- LTV (Пожизненная ценность)        -> Средний платёж / Churn (₽).
- Churn (Отток)                     -> Доля ушедших клиентов за месяц (%).
- Runway (Запас денег)              -> Деньги / Месячные расходы (месяцы).
- Retention M1/M3/M6/M12            -> Доля клиентов, активных через 1,3,6,12 мес. (%).
- LTV/CAC (Эффективность)           -> Во сколько раз LTV больше CAC (>3 - хорошо).
- Magic Number                      -> Прирост дохода / Затраты на продажи (>1 - хорошо).

10. AI-ПРОГНОЗ НАЙМА СОТРУДНИКОВ (СОГЛАСОВАННЫЙ АЛГОРИТМ)
Алгоритм:
1. Определяем отрасль (SaaS, Fintech и т.д.).
2. Берём отраслевые коэффициенты распределения штата (например, для SaaS: 40% разработка, 25% продажи и т.д.).
3. Берём финансовые ограничения (Бюджет на ФОТ = 30-40% от прогнозного MRR).
4. Рассчитываем целевой штат на 12 месяцев с разбивкой по месяцам.

Настройки соц. платежей (РЕДАКТИРУЮТСЯ ВРУЧНУЮ КЛИЕНТОМ):
+-----------------------------------------------------+
| Параметр                    | Значение по умолчанию |
+-----------------------------+-----------------------+
| НДФЛ                        | 13%                   |
| Страховые взносы (ОПС+ОМС)  | 30%                   |
| Взносы на травматизм        | 0.2%                  |
+-----------------------------+-----------------------+
Итоговый процент соц. платежей рассчитывается автоматически как сумма этих полей.

11. P&L (ОТЧЁТ О ПРИБЫЛЯХ И УБЫТКАХ)
Структура:
- Выручка (MRR + Единовременные доходы)
- Операционные расходы (ФОТ, Соц. платежи, Маркетинг, Разработка, G&A)
- EBITDA (Выручка - OPEX)
- Чистая прибыль (EBITDA - Финансовые расходы)

12. CASH FLOW (ДВИЖЕНИЕ ДЕНЕЖНЫХ СРЕДСТВ)
Структура:
- Операционный CF (Чистая прибыль + Корректировки)
- Инвестиционный CF (Покупка ОС)
- Финансовый CF (Инвестиции, Кредиты)
- Итого CF, Остаток на начало/конец месяца.

14. ОЦЕНКА БИЗНЕСА ПО МОДЕЛИ ГОРДОНА
Формула: TV = FCF * (1 + g) / (r - g)
- r (ставка дисконта) = Ключевая ставка + 10% (премия за риск).
- g (темп роста) = Прогноз инфляции (из внешнего анализа).
- Итог: Equity Value = TV - Чистый долг.
- Мультипликаторы: P/S, Оценка на 1 сотрудника.
